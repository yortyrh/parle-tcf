# 🤖 TCF LiveKit Agent

Module Node.js gérant l'intelligence de l'examinateur IA.

## 📁 Structure
- `src/` : Code source de l'agent.
- `config/` : Prompts YAML et base de données des exercices.
- `railway.json` : Configuration de déploiement Railway.
